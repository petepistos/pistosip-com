Security Baseline

EZLynx Minimum Security Baseline

The settings every Pistos client's EZLynx should have, where to find them, and how to prove they are on.

Product: EZLynx Rating Engine and Management SystemAudience: Agency owners, office managers, IT providersFramework: CIS Controls v8.1, IG1Version: 1.0, November 2026

EZLynx holds every applicant's personal details, quotes and policies. EZLynx sets several security rules for every agency on its own, and some changes can only be made by EZLynx support. This page says which settings the agency controls and which ones need an email to support@ezlynx.com.

How to read this

Minimum items are required for a Pistos client. Recommended items are what we set up when the agency agrees. Each item names the CIS Controls v8.1 safeguard it supports, so it lines up with the PCS risk assessment.

What EZLynx already does for every agency

ControlEZLynx setting (fixed)
Password rulesAt least 8 characters with an uppercase letter, a lowercase letter and a number; change prompted every 90 days

The standards

1

One named login for every person

MinimumCIS v8.1: 4.7, 5.1
Where

Agency Admin icon > Manage Users

The standard
  • Every person who uses EZLynx has their own login in their own name.
  • No shared logins, and none left over from a past employee, a vendor or a trainer.
How to check it

Compare Manage Users with the PCS staff roster.

2

Two-factor authentication on, using an app

MinimumCIS v8.1: 6.3, 6.5
Where

User icon > User Settings > Two Factor

The standard
  • Every user is enrolled in two-factor sign-in.
  • The main method is an authenticator app (Microsoft Authenticator is fine). Text messages are a backup only.
  • Every user adds a second method so a lost phone doesn't lock them out.
What the product can't do, and what to do instead

EZLynx's help does not show an administrator setting that forces two-factor for every user or reports who is enrolled. Check each user's Two Factor tab, and ask EZLynx support to confirm two-factor is required for the agency. Keep their answer in PCS.

How to check it

Sit with each user once and open their Two Factor tab. Record the date in PCS.

3

Two administrators at most

MinimumCIS v8.1: 5.4
Where

Agency Admin icon > Manage Users; Management System access is changed by emailing support@ezlynx.com

The standard
  • No more than two people hold Agency Admin rights or Management System Admin Access (commissions, policy management reports and unmatched downloads). Everyone else has Basic User Access.
  • When adding a user with Clone User, clone from someone in the same role, never from an administrator.
How to check it

Review Manage Users and the access list EZLynx support confirms.

4

Strong, unique passwords

MinimumCIS v8.1: 5.2
Where

User icon > User Settings > Change Password

The standard
  • At least 14 characters by agency policy, not used for any other system, stored in a password manager. EZLynx's own minimum of 8 is too short.
How to check it

Confirmed on the PCS line-of-business access form, signed by the agency.

5

Access matches the job

RecommendedCIS v8.1: 3.3
Where

Email support@ezlynx.com

The standard
  • By default every user sees every applicant in their office. Ask support to set No Peer Access for anyone who should see only the applicants assigned to them.
  • Keep Admin Application Manager (seeing every branch) to the owner or office manager.
How to check it

Keep support's confirmation email in PCS.

6

Support login turned off when not needed

MinimumCIS v8.1: 6.1
Where

User icon > User Settings > Preferences > General

The standard
  • Uncheck allow technical Support Representatives to login with you. Turn it on only while a support case is open, then turn it off again.
Why

EZLynx's help suggests leaving this on for convenience. For an agency holding client personal data, nobody outside the agency should be able to sign in as a user without a reason.

How to check it

Spot-check users' Preferences each quarter.

7

Leavers turned off the same day

MinimumCIS v8.1: 5.3, 6.2
Where

Agency Admin icon > Manage Users, and email support@ezlynx.com

The standard
  • On the person's last day, remove their access and email support@ezlynx.com to remove any Management System access.
  • Any account nobody has signed in to for 45 days is reviewed and removed if it is not needed.
How to check it

Each month, compare Manage Users with the PCS roster. Keep support's confirmation emails.

8

Login activity reviewed every month

MinimumCIS v8.1: 8.2
Where

User icon > User Settings > Login Activity

The standard
  • Once a month, the office manager or Pistos looks at each user's Login Activity for odd hours or unknown places.
  • Ask EZLynx support for an agency-wide login report if one is available.
What the product can't do, and what to do instead

EZLynx shows login activity per user, not as one agency report. Microsoft 365 sign-in logs and Intune device rules help cover the gap.

How to check it

A note of each monthly review is kept in PCS.

9

Signature sharing off

MinimumCIS v8.1: 3.3
Where

User icon > User Settings > ACORD Forms

The standard
  • Uncheck Allow all users in your agency to use your signature for every licensed producer, unless the agency has written permission from that producer.
How to check it

Spot-check producers' ACORD Forms settings each quarter.

10

Vendor security and backup evidence on file

MinimumCIS v8.1: 11.2, 11.3, 11.4, 15.1
The standard
  • EZLynx (Applied Systems) is listed as a vendor in PCS with an agency contact.
  • EZLynx's current SOC report and backup statement are uploaded to PCS and renewed when they expire.
How to check it

PCS shows the vendor evidence as received and not expired.

Sign-off checklist

  • Manage Users matches the staff roster; no shared, vendor or leftover logins
  • Every user enrolled in two-factor with an authenticator app, checked in person
  • Two or fewer administrators; everyone else on Basic User Access
  • Password rule (14+ characters, password manager) signed on the PCS form
  • No Peer Access set where producers should see only their own applicants
  • Support login checkbox off for every user
  • Leaver process and 45-day dormant review in place
  • Monthly login activity review noted in PCS
  • Signature sharing off unless approved in writing
  • EZLynx SOC report and backup statement in PCS
