Agency Management System Security Baselines

Minimum security settings for the systems insurance agencies run on.

Audience: Agency owners, office managers, IT providersFramework: CIS Controls v8.1, IG1Version: 1.0, November 2026

Every Pistos client runs its business on an agency management system. These pages set the minimum security settings we expect in each one, where to find them, and how to prove they are on. Each standard lines up with the CIS Controls v8.1 safeguards in the PCS risk assessment.

HawkSoft

HawkSoft 6 and HawkSoft Cloud. 12 standards.

AMS360

Vertafore AMS360 with Vertafore Single Sign-On. 11 standards.

EZLynx

EZLynx Rating Engine and Management System. 10 standards.

What every baseline has in common

  • One named login per person, with no shared, vendor or leftover accounts
  • A second sign-in step for every user
  • Two administrators at most, and Pistos's admin login used only for administration
  • Passwords of 14 or more characters, kept in a password manager
  • Permissions that match each person's job
  • Leavers turned off on their last day, and unused accounts reviewed after 45 days
  • Sign-in activity reviewed every month
  • The vendor's security report and backup statement on file in PCS
