Security Baseline

HawkSoft Minimum Security Baseline

The settings every Pistos client's HawkSoft should have, where to find them, and how to prove they are on.

Product: HawkSoft 6 and HawkSoft CloudAudience: Agency owners, office managers, IT providersFramework: CIS Controls v8.1, IG1Version: 1.0, November 2026

HawkSoft holds every client's personal details, policies and payments. This page sets the minimum security settings Pistos expects in HawkSoft 6 and HawkSoft Cloud. Most of these are one-time settings an administrator can make in under an hour.

How to read this

Minimum items are required for a Pistos client. Recommended items are what we set up when the agency agrees. Each item names the CIS Controls v8.1 safeguard it supports, so it lines up with the PCS risk assessment.

The standards

1

One named login for every person

MinimumCIS v8.1: 4.7, 5.1
Where

Setup > User Setup > User List

The standard
  • Every person who uses HawkSoft has their own login in their own name.
  • No shared logins such as "frontdesk" or "csr." No logins left over from a past employee, a vendor or a trainer.
  • Every user's Account Email is verified, because password resets and MFA codes go there.
How to check it

Compare the User List with the staff roster in PCS. Every active user should match a current person.

2

Multi-factor authentication on for everyone

MinimumCIS v8.1: 6.3, 6.5
Where

Setup (gear) > General Configuration > General Settings > Additional Settings > Multi-Factor Authentication

The standard
  • Multi-Factor Authentication is enabled.
  • Days between prompts is set to 30 or fewer. HawkSoft allows up to 180; that is too long for an agency.
  • Each person's Account Email is a mailbox only they can read, protected by its own MFA in Microsoft 365.
What the product can't do, and what to do instead

HawkSoft's MFA sends the code to the user's email. If someone breaks into that mailbox, they get the code too. That is why the mailbox itself must have strong MFA, and why item 11 matters.

How to check it

Sign in from a new computer or browser. HawkSoft should ask for the emailed code.

3

Two administrators at most

MinimumCIS v8.1: 5.4
Where

Setup > User Setup > User List > user > Permissions > Open Permissions Editor > Agency Setup

The standard
  • No more than two people hold User Setup, General Configuration, Agency/Office Setup or Carrier Setup. Usually that is the owner and one manager.
  • Pistos's administrator login is used only for administration, never for daily work.
  • Nobody can change their own permissions. HawkSoft enforces this.
How to check it

Open the Permissions Editor for each user and count who has any Agency Setup right.

4

Strong, unique passwords

MinimumCIS v8.1: 5.2
Where

Profile icon > My Account > Info > Password

The standard
  • At least 14 characters, not used for any other system.
  • Stored in a password manager, never on a sticky note or in a spreadsheet.
What the product can't do, and what to do instead

HawkSoft does not publish a setting that forces password length or history. The agency enforces this by policy, and the PCS form records that it does.

How to check it

Confirmed on the PCS line-of-business access form, signed by the agency.

5

Auto logout after 15 minutes

MinimumCIS v8.1: 4.3
Where

Setup > General Configuration > General Settings > Auto Logout

The standard
  • Set to 15 minutes. The default is 30, and the setting allows 2 to 480. Never enter 0: that means 480 minutes (8 hours).
How to check it

Leave HawkSoft idle for 15 minutes. It should sign you out.

6

Personal information masked

MinimumCIS v8.1: 3.3
Where

Setup > General Configuration > General Settings > Additional Settings

The standard
  • Mask Personally Identifiable Information is on. It is on by default; confirm nobody turned it off.
  • PDF Security is on.
How to check it

Open a client's People screen. Social Security and driver's license numbers should show masked until someone clicks to unmask.

7

Permissions match the job

MinimumCIS v8.1: 3.3, 5.4
Where

Setup > User Setup > User List > user > Permissions

The standard
  • Allow running reports with unmasked PII: owner and one manager only.
  • Allow Exporting of Report Data: only people who need it for their job.
  • Archive Client, Archive/Move Policies, Mass Data Importer and Change Agent Code: managers only.
  • Accounting, Commissions and Trust Accounting rights: the bookkeeper and the owner only.
  • Allow Agent Portal Access: only people who use the portal.
  • Use a permission template per role so new hires start with the right set.
What the product can't do, and what to do instead

HawkSoft lets any user unmask a number on screen; only unmasked reports are controlled by a permission. Train staff to unmask only when they need to, and keep item 10's log review in place.

How to check it

Export the user list and review each person's permissions once a quarter. Keep the reviewed copy in PCS.

8

Remember Me turned off

MinimumCIS v8.1: 5.2
Where

Setup > General Configuration > General Settings

The standard
  • Show Remember Me Checkbox on Desktop Login is off, so passwords are not stored on the computer.
How to check it

The desktop sign-in screen shows no Remember Me box.

9

Leavers turned off the same day

MinimumCIS v8.1: 5.3, 6.2
Where

Setup > User Setup > User List > user > Status

The standard
  • When someone leaves, set their status to Inactive on their last day. That blocks HawkSoft and the Agent Portal while keeping their history.
  • Any account nobody has signed in to for 45 days is reviewed and made Inactive if it is not needed.
  • Force sign-out of the person under Licensed Seat Management if they are still signed in.
How to check it

Each month, compare active users with the PCS roster and the sign-in log.

10

Sign-in log reviewed every month

MinimumCIS v8.1: 8.2, 8.3
Where

Setup > User Setup > View and Export User Sign-In Logs

The standard
  • Once a month, export the sign-in log to CSV and look for sign-ins at odd hours, from unexpected places, or from people who have left.
  • Keep each month's export for at least a year in PCS or the agency's document store.
  • Leave Automatically Append Task Info on Edit on, so task changes stay logged.
How to check it

The last twelve monthly exports are on file.

11

Logins limited to the office and approved places

MinimumCIS v8.1: 6.3, 4.6
Where

Setup > Agency Setup > Settings > IP Access Management

The standard
  • Add the office's internet address, and any approved home addresses, as Allow IP Address rules.
  • Apply the rules to All Administrator Users at minimum, and to all users where the agency's staff work from fixed locations.
  • Turn on Enable IP Enforcement only after confirming the rules from the office. A missing rule locks people out.
Why

This covers the HawkSoft desktop, the browser app and the Agent Portal. It is the strongest protection HawkSoft offers against a stolen password plus a broken-into mailbox.

How to check it

From a phone hotspot, an administrator login should be refused.

12

Vendor security and backup evidence on file

MinimumCIS v8.1: 11.2, 11.3, 11.4, 15.1
The standard
  • HawkSoft is listed as a vendor in PCS with an agency contact.
  • HawkSoft's current security report (SOC 2 or equivalent) and backup statement are uploaded to PCS and renewed when they expire.
How to check it

PCS shows the vendor evidence as received and not expired.

Sign-off checklist

  • User List matches the staff roster; no shared, vendor or leftover logins
  • Multi-Factor Authentication on, 30 days or less between prompts
  • Two or fewer people with Agency Setup rights
  • Password rule (14+ characters, password manager) signed on the PCS form
  • Auto Logout set to 15 minutes
  • Mask Personally Identifiable Information and PDF Security on
  • Unmasked reports, export, archive and accounting rights limited by role
  • Remember Me checkbox turned off
  • Leaver process and 45-day dormant review in place
  • Monthly sign-in log export on file
  • IP Access Management enforced for administrators
  • HawkSoft security and backup evidence in PCS
